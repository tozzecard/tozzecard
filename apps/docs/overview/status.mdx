## One card per agent

The hosted agent refills one card: the one in its Agentic Wallet's address book. Anyone can create and activate a card, top it up and use the app. The **Card | Agent** switch on Home appears only for the card the agent refills.

This comes from how the Agentic Wallet works today: one wallet per Binance account, driven by one `baw` CLI session, with no HTTP API. See [Agent wallet](/learn/agent-wallet).
