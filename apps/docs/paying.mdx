---
title: "Paying a merchant"
description: "B402 (x402 v2) with an EIP-3009 authorization signed by the card."
---

```ts
import { paymentHeader, transferAuthorization } from "@tozzecard/binance/eip3009";

const payUrl = `${API}/merchant/orders/${orderId}/pay`;

// 1. The merchant answers 402 with what it accepts.
const { accepts } = await fetch(payUrl).then((r) => r.json());
const req = accepts[0];

// 2. The card signs a USD1 transfer authorization for exactly that.
const { authorization, typedData } = transferAuthorization(req, account.address);
const signature = await account.signTypedData(typedData);

// 3. Send it back; the merchant verifies and settles through B402.
const res = await fetch(payUrl, {
  method: "POST",
  headers: { "PAYMENT-SIGNATURE": paymentHeader(payUrl, req, authorization, signature) },
});
const order = await res.json(); // status: "paid", tx: BSC tx hash
```

The card holds no BNB at any point: B402 submits the transaction and pays the gas.
