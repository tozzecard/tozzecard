| Term | Meaning |
|---|---|
| **Address book** | The list of addresses your Agentic Wallet may send to. Edited only in the Binance App |
| **Agentic Wallet** | Binance's wallet for software agents, in your Binance App, driven through the `baw` CLI |
| **`baw`** | Binance's command-line tool for the Agentic Wallet (`@binance/agentic-wallet`) |
| **B402** | Binance's x402 payment facilitator on BNB Chain. Submits payments and pays their gas |
| **bStock** | A tokenized stock issued by Binance, such as NVDAB |
| **Close reference** | The per-share price at the last regular-session close, recorded by the Tozzecard API |
| **Developer Mode** | An Agentic Wallet setting that allows arbitrary contract calls. Keep it off |
| **Dry mode** | The agent decides and logs but never trades |
| **EIP-3009** | A token standard for signed transfers: the holder signs, someone else submits |
| **EOA** | A plain wallet controlled by one key, not a smart contract |
| **MPC** | Multi-party computation: a key split so no single party holds all of it |
| **Ondo** | Issuer of tokenized stocks such as NVDAon |
| **Passkey** | A sign-in key stored by your device or password manager, unlocked with Face ID or a fingerprint |
| **PRF** | A passkey feature that returns the same secret bytes each time. The card's key is made from them |
| **Rebalance** | Selling overweight stocks and buying underweight ones to get back to your split |
| **Refill** | The agent selling a stock and sending USD1 to your card |
| **Spread** | How far the price you can get is from the close reference |
| **USD1** | The US dollar stablecoin the card holds and pays with |
| **x402** | A standard for paying over HTTP: the server answers `402 Payment Required` with its terms |
